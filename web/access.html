Access the data

The estimates are published as a GeoZarr pyramid. xarray opens it lazily over HTTP, so only the chunks you select are downloaded.

Open the store

Level 0 of the pyramid is the full 0.25° grid at 8-day resolution. You need xarray, zarr, fsspec, aiohttp and dask.

import xarray as xr

store = "https://data.up.ethz.ch/shared/OceanSODA-ETHZv2/.total_alkalinity/highresTA-8D_025deg-stacked_salinity_model-20261109.zarr/"
ds = xr.open_zarr(store, group="0")
ds

The root of the store holds only metadata. The coarser pyramid levels are the other groups listed in its multiscales attribute.

Example

# one 8-day field
ta = ds.talk_median.sel(time="2021-05-21", method="nearest")

# uncertainty at the same time, and one of its components
sigma = ds.talk_total_stdev.sel(time="2021-05-21", method="nearest")
split_var = ds.talk_var.sel(variance_type="var_split", time="2021-05-21", method="nearest")

# time series at a point (latitude runs from north to south)
point = ds.talk_median.sel(lat=32.0, lon=-64.0, method="nearest").load()

# a regional subset, downloaded only when computed
med = ds.talk_median.sel(lat=slice(46, 30), lon=slice(-6, 36)).sel(time="2021").load()
